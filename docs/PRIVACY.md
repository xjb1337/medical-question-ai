# 隐私与数据处理说明

## 数据流

1. 用户拍摄或选择图片后，应用在本地完成方向校正、缩放和 JPEG 重编码。
2. 点击「开始解析」时，题目文字、选中的图片（Base64）和题型会通过 HTTPS 直接发送到用户配置的 DeepSeek API 地址。
3. 模型返回的题干、答案、解析和用量保存在本机 Room 数据库；图片保存在应用私有目录。
4. 应用没有自建中转服务器，也不包含统计 SDK、广告 SDK 或第三方登录。

## 本地保存

| 数据 | 位置 | 说明 |
| --- | --- | --- |
| API Key | `EncryptedSharedPreferences`（`secure_settings`） | 使用 Android Keystore 的 AES-256-GCM 加密 |
| 题目与解析 | Room `medical_question.db` | 包含题干、答案、模型名、时间、收藏状态 |
| 追问记录 | Room `follow_ups` 表 | 与题目关联，删除题目时一并删除 |
| 图片 | `filesDir/question_images/` | 应用私有目录，卸载应用时删除 |
| 普通设置 | `SharedPreferences`（`app_settings`） | 模型名、接口地址、是否保存历史 |

## 用户控制

- 设置页可清除 API Key。
- 历史页可删除单条记录或清空全部历史。
- 关闭「保存历史」后，新解析仍会展示结果，但不会出现在历史列表；该次记录仅在本机临时保留以便展示，可在历史页「清空全部」时一并删除。收藏后会自动转为普通历史记录。
- 删除题目时会删除其关联的追问和图片文件。

## 图片与患者信息

- 上传前必须勾选隐私确认。
- 图片重编码为 JPEG 时会丢弃 EXIF 元数据，但**不能**保证图片像素中不含姓名、住院号、床号、日期等可见信息。
- 涉及真实患者时，用户应在上传前自行遮挡所有身份信息，并遵守所在机构的资料管理规定。

## 模型侧风险

- DeepSeek 会接收题目图片和文字；其保存、使用方式受 DeepSeek 服务条款和隐私政策约束。
- 图片在模型侧可能被缩放，细小文字、波形和影像细节可能丢失。
- 模型输出可能出错，尤其是心电图、影像学和少见病内容；应用内的把握程度和警告只作提示，不构成保证。

## 日志

应用不主动上传崩溃日志。调试构建的 Logcat 仅用于本地排障，不应记录 API Key、完整图片内容或患者身份信息。
